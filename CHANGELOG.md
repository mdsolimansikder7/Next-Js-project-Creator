# Changelog

All notable changes to the "Next.js One-Click Project Creator" extension are documented here.

## [0.0.1] - 2026-11-04

### Added
- Sidebar form to create a Next.js project with one click (runs `create-next-app@latest`).
- Language choice: TypeScript (tsx) or JavaScript (jsx).
- Linter choice: ESLint, Biome or None.
- Options: Tailwind CSS, React Compiler, AGENTS.md, `src/` directory, App Router, Turbopack.
- Cache Components setting: Default, Enable or Disable.
- Import alias and package manager (npm, pnpm, yarn, bun).
- "After creating" behavior: ask, open in this window, or open in a new window.
- "Save as defaults" button to store your preferred settings.
- Status bar button and `Next.js: Create Project` command.
